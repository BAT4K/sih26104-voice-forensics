# Voice Forensics Platform (SIH 2026)

An advanced, real-time Voice Forensics Platform designed to detect state-of-the-art AI-generated speech (deepfakes) and human mimicry on telephony channels.

## Core Capabilities

1. **AI Voice Clone Detection:** Detects deepfakes generated by 6 major neural vocoder families (HiFi-GAN, BigVGAN, Vocos, EnCodec, modern codecs like DAC, and legacy autoregressive models).
2. **Cross-Session Speaker Verification (Mimicry Detection):** Utilizes ECAPA-TDNN biometric voiceprints to catch professional human impersonators (which easily bypass standard AI detectors).
3. **Telephony Degradation Resilience:** Specifically engineered and evaluated to handle audio degraded by low-bitrate telephony compression (like G.711 µ-law).
4. **Real-time Alerting System:** Automatically dispatches JSON Webhooks and Email alerts to security teams the moment a high-risk deepfake or impersonator is detected.

## Project Structure

*   `/src` - The core FastAPI backend and Machine Learning pipeline (Wav2Vec2 + ECAPA-TDNN).
*   `/frontend` - The Next.js / React interactive dashboard for real-time forensic analysis.
*   `/general_ml_demo` - pristine and G.711-degraded test audio files for generic deepfake detection across 4 Indic languages.
*   `/narendra_modi_demo` - The High-Profile target dataset for testing cross-session mimicry and voice cloning.

## Quick Start Guide

### 1. Start the Backend API
You will need a python 3.11+ environment with PyTorch installed.
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn src.api:app --host 0.0.0.0 --port 8000
```

### 2. Start the Frontend Dashboard
Open a new terminal window.
```bash
cd frontend
npm install
npm run dev
```
Navigate to `http://localhost:3000` in your web browser.

## Running the Demo

1. **Generic AI Detection:** Drag and drop audio files from `general_ml_demo/fake/` into the UI. The system will process the audio, flag it as an **AI-Generated Voice**, and identify the specific neural codec family used to create it.
2. **Human Mimicry Defense:** 
    * Go to Settings in the UI and set the target Speaker ID to `narendra-modi`.
    * Drag and drop `narendra_modi_demo/eval/mimicry/mim2_trumpcall.wav`.
    * The system will correctly identify this as a real human speaking (Low AI Risk), but the biometric voiceprint will explicitly reject the impersonator, flagging the audio as **Human Mimicry**.

## Automated Webhook Alerts
The system is configured to instantly fire alerts when a high-risk voice is detected.
1. Go to `http://localhost:3000/settings`.
2. Enter a webhook URL (e.g., from [webhook.site](https://webhook.site/)).
3. Upload any high-risk deepfake audio.
4. Watch the alert payload instantly arrive at your webhook!
