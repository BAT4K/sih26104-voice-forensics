# Backend Architecture & Feature Overview

This document summarizes the current state of the backend pipeline, detailing the feature set, the model architecture, and the recent stability patches applied before final delivery.

## 1. The Core AI Pipeline

The system is built on a multi-tiered forensic architecture to analyze audio files and detect deepfakes generated by modern TTS and voice conversion models.

*   **Backbone:** Uses Facebook's `wav2vec2-xls-r-300m`. This multilingual transformer is incredibly sensitive to phonetic structures, allowing it to extract robust acoustic features even after heavy telephony compression.
*   **Tier 1 (Spoof Detection):** A binary classifier trained to detect if the audio is authentic (Real) or AI-generated (Synthetic).
*   **Tier 2 (Vocoder Attribution):** A multi-class head that classifies the specific neural synthesis family used to generate the audio. The 5 tracked families are:
    *   `hifigan` (e.g., XTTS-v2, Piper)
    *   `vocos` (e.g., IndicF5, F5-TTS)
    *   `encodec` (e.g., Suno Bark)
    *   `modern_codec` / DAC (e.g., Parler-TTS)
    *   `legacy_ar` (older autoregressive models)
*   **Tier 3 (Novelty Detection):** Calculates the Mahalanobis distance of the audio's embeddings against known training clusters. If the distance is too high, it flags the audio as an "Unknown System" (a zero-day attack).
*   **Tier 4 (Speaker Verification):** Uses an ECAPA-TDNN architecture to extract 192-dimensional x-vectors. This enforces cross-session consistency, proving if the speaker is actually who they claim to be (blocking human impersonators).

## 2. API Architecture (FastAPI)

The inference pipeline is wrapped in a production-ready FastAPI server located at `server/api.py` (and `src/api.py`).

*   **Endpoint:** `POST /v1/detect`
*   **Flow:** 
    1. Receives an audio file (`.wav`, `.mp3`, `.ogg`).
    2. Securely writes to a temporary file via `tempfile`.
    3. Loads the audio using `soundfile` into a numpy array.
    4. Passes the array through the `analyse()` pipeline.
    5. Returns a structured JSON payload mapped for the Next.js frontend.

## 3. Recent Stability & Professionalism Patches

Several critical patches were applied to make the backend bulletproof for presentation:

1.  **Global Traceback Error Handling:** The FastAPI endpoints are now wrapped in a global `try/except` block. If a corrupted audio file is uploaded, the server no longer crashes. Instead, it gracefully returns a 500 error containing the exact Python traceback, which the Next.js frontend is configured to read and display.
2.  **Safetensors Support:** `src/model_loader.py` was heavily patched to seamlessly load HuggingFace's new `.safetensors` format (instead of just legacy `.bin` files). It also features a fallback mechanism to instantiate the default architecture even if `vfd_config.json` is missing.
3.  **Professional Scrubbing ("VFD"):** The entire codebase originally used the internal joke name.  This was globally refactored to **VFD** (Voice Forensic Detector). 
    *   The checkpoint is now `checkpoints/vfd-v1`.
    *   All environment variables (e.g., `VFD_LOG_LEVEL`) and internal loggers have been updated.

## 4. How to Review & Make Changes

To review the model code, look into the `src/` directory:
*   `src/inference.py`: Controls the execution flow of the model.
*   `src/model_loader.py`: Handles loading weights into PyTorch.
*   `src/speaker.py`: Manages the ECAPA-TDNN speaker enrollments.
*   `train.py`: The script used on Kaggle/Colab to train the `wav2vec2` backbone.
